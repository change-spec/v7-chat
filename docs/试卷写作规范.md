# 试卷写作格式规范（所有命题 agent 必读）

## 🚨 最重要的一条：绝对禁止 LaTeX

**不要写 `$...$`，不要写 `\frac`、`\times`、`\sqrt`、`\text`、`\left` 等任何 LaTeX 命令。**

原因：这些 Markdown 文件最终要在 Word / WPS 里打印给老师和学生看，Word **不渲染 LaTeX**，
学生看到的会是一串乱码般的 `$\dfrac{1}{3}$`，完全无法阅读。这是要出事故的。

## 数学符号怎么写（照着这个表）

| 含义 | ✅ 正确写法 | ❌ 错误写法 |
|---|---|---|
| 乘号 | `3 × 4`（用 ×，U+00D7） | `3 \times 4` |
| 除号 | `12 ÷ 3` | `12 \div 3` |
| 负号 | `-5`（半角减号） | `- 5` |
| 等号 | `=` | — |
| 不等号 | `≥` `≤` `≠` | `\ge` `\le` `\ne` |
| 约等于 | `≈` | `\approx` |
| 角度 | `35°` | `35^\circ` |
| 角 | `∠ABC` | `\angle ABC` |
| 圆周率 | `π` | `\pi` |
| 垂直 | `AB ⊥ CD` | `AB \perp CD` |
| 平行 | `AB ∥ CD` | `AB \parallel CD` |
| 根号 | `√9` | `\sqrt{9}` |
| 三角形 | `△ABC` | `\triangle ABC` |
| 相似 | `△ABC ∽ △DEF` | `\sim` |
| 约等/无限不循环小数 | `≈` / `1.333...` | `\approx` / `\cdots` |

## 分数怎么写（关键）

**不要用分式堆叠**，用斜杠或除号：

| 含义 | ✅ 写法 |
|---|---|
| 分数 1/3 | `1/3` |
| 带负号的分数 | `-2/3` |
| 分数加减混合 | `1/3 + 1/2 - 5/6` |
| 分数作除数 | `2 ÷ (1/3)` |

常用分数也可用 Unicode 符号（更美观）：½ ⅓ ⅔ ¼ ¾ ⅕ ⅖ ⅗ ⅘ ⅙ ⅚ ⅐ ⅛ ⅜ ⅝ ⅞

**判断：只要公式里有斜杠 `/`，两边都应该是纯数字**，例如 `3/4`、`-5/6`、`(1+2)/3`。

## 上标下标

- 平方：`x²`（用 ² 字符），立方：`x³`
- 不要写 `x^2` 或 `x^{2}`
- 下标同理：`a₁` `a₂`

## 单位

- 长度：cm、m、km、mm
- 面积：cm²、m²（用 ²）
- 体积：cm³、m³（用 ³）
- 角度：°（用 ° 字符）
- 钱：元（不要用 LaTeX 的 \text）

## 整篇文档的其他要求

1. **不要出现 `↵` 符号** —— 那是软换行符，不要手打进去
2. **不要出现空行过多的段落**（连续空行最多 2 个）
3. **题目编号连续**，不要跳号
4. **答案与题目必须一一对应**，不能有「略」「答案同上」「（下略）」
5. **数学符号与数字之间不要有多余空格**：`3×4` 不是 `3 × 4`（乘号两边不空格更紧凑，但加减号两边留一个空格）
6. 中文标点：，。、；：？！（）「」
7. 全角括号 `（　　）` 用于填空，全角括号里放 2 个全角空格表示答题位
